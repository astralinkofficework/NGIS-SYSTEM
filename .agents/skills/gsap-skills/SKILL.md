# GSAP Skills Suite

Official AI skills for **GSAP (GreenSock Animation Platform)**.

## Available Skills

- [gsap-core](../gsap-core/SKILL.md): Core tweening (`gsap.to`, `from`, `fromTo`), easing, stagger, defaults, matchMedia (responsive/reduced-motion).
- [gsap-timeline](../gsap-timeline/SKILL.md): Timelines, position parameters, nesting, playback controls.
- [gsap-scrolltrigger](../gsap-scrolltrigger/SKILL.md): ScrollTrigger, scroll-linked animations, pinning, scrubbing, parallax.
- [gsap-plugins](../gsap-plugins/SKILL.md): Plugins registration, ScrollSmoother, Flip, Draggable, Inertia, SplitText, SVG plugins.
- [gsap-react](../gsap-react/SKILL.md): React & Next.js integration (`useGSAP`, refs, `gsap.context`, cleanup).
- [gsap-frameworks](../gsap-frameworks/SKILL.md): Vue, Nuxt, Svelte, SvelteKit scoping, lifecycles, and cleanup.
- [gsap-performance](../gsap-performance/SKILL.md): GPU transforms, avoiding layout thrashing, will-change, 60fps optimization.
- [gsap-utils](../gsap-utils/SKILL.md): Helper utilities (`clamp`, `mapRange`, `interpolate`, `random`, `snap`, `toArray`, `wrap`).
