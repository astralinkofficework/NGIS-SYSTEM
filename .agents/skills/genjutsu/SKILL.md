# genjutsu — The Art of Illusion

Creative coding suite for interface motion, art direction, and website generation.

## Primary Workflows

1. **Cast** ([cast](../cast/SKILL.md)):
   - Creative coding for motion, micro-interactions, and wow-factor.
   - Stack-adaptive (GSAP, Framer Motion, Canvas, Three.js, native CSS).
   - Formulates and validates an interaction thesis, loads sub-modules from `_jutsu`, and implements 60fps animations.

2. **Paint** ([paint](../paint/SKILL.md)):
   - Art direction brainstorm and design system generation.
   - Anti-AI-slop design pipeline.

3. **Bunshin** ([bunshin](../bunshin/SKILL.md)):
   - Full website and web app generator from scratch or full redesign.

## Modules

Supporting modules located in `../_jutsu/`:
- `gsap`: Advanced GreenSock timelines, ScrollTrigger, and plugins.
- `threejs-r3f`: Three.js and React Three Fiber rendering.
- `framer-motion`: Declarative React animations.
- `canvas-generative`: HTML5 Canvas procedural animations and shaders.
- `motion-principles`: Physics, choreographies, timing curves.
- `design-audit`: UX and animation performance audits.
