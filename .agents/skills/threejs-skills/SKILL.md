# Three.js Skills Suite

Targeting **Three.js r186**, **React Three Fiber 9.8**, **drei 10.7**, and **gltf-transform 4.5**.

## Available Skills

- [threejs-fundamentals](../threejs-fundamentals/SKILL.md): Scene, cameras, renderer setup, animation loop, object hierarchy, transforms.
- [threejs-geometry](../threejs-geometry/SKILL.md): Built-in shapes, BufferGeometry, merging, instancing, BatchedMesh, points, lines.
- [threejs-materials](../threejs-materials/SKILL.md): Material types, PBR, blending, stencil, node materials.
- [threejs-lighting](../threejs-lighting/SKILL.md): Light types, physical units, shadows, HDR environments, light probes.
- [threejs-textures](../threejs-textures/SKILL.md): Loading, color spaces, UV channels, texture types, render targets, memory.
- [threejs-animation](../threejs-animation/SKILL.md): Keyframes, animation mixer, skeletal & morph animation, blending.
- [threejs-loaders](../threejs-loaders/SKILL.md): glTF with Draco, meshopt, KTX2, HDR, progress, disposal.
- [threejs-shaders](../threejs-shaders/SKILL.md): ShaderMaterial, RawShaderMaterial, shader chunks, TSL and node materials.
- [threejs-postprocessing](../threejs-postprocessing/SKILL.md): EffectComposer, built-in renderer effects, WebGPU RenderPipeline.
- [threejs-interaction](../threejs-interaction/SKILL.md): Raycasting, camera controls, transform gizmos, drag & box selection.
- [threejs-performance](../threejs-performance/SKILL.md): Frame cost, draw calls, GPU memory, fill rate, compile stalls.
- [threejs-react-three-fiber](../threejs-react-three-fiber/SKILL.md): React Three Fiber 9 and verified drei helpers on WebGL or WebGPU.
- [threejs-asset-pipeline](../threejs-asset-pipeline/SKILL.md): gltf-transform, Draco, meshopt, KTX2, WebP optimization.
