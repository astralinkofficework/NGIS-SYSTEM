01. Mathematically Correct Nested Corner Radii

Inner radius = Outer radius − Inset distance. Prevents visual distortion and pinched borders.

Outer 24px → Inner 16px Inset: 8px (24 − 8 = 16px)
--radius-container (24px) → --radius-xl (16px)
Outer 20px → Inner 12px Inset: 8px (20 − 8 = 12px)
--radius-2xl (20px) → --radius-lg (12px)
Outer 16px → Inner 8px Inset: 8px (16 − 8 = 8px)
--radius-xl (16px) → --radius-md (8px)
Outer 12px → Inner 8px Inset: 4px (12 − 4 = 8px)
--radius-lg (12px) → --radius-md (8px)

02. Universal Button Size System & Balanced Padding

Exactly three text-button sizes + icon-only variant. Consistent height, typography, optical gaps, and padding.

Small Button (.btn-sm)

Height: 36px | Font: 14px | Icon: 16px | Pad: 12px | Gap: 6px | Radius: 8px

Usage: Compact desktop table actions, toolbar filters
Medium Button (Standard .btn / .btn-md)

Height: 40px | Font: 14px | Icon: 20px | Pad: 16px | Gap: 8px | Radius: 8px

Usage: Standard forms, navigation, management workflows
Large Button (.btn-lg)

Height: 56px | Font: 16px | Icon: 24px | Pad: 24-32px | Gap: 8px | Radius: 12px

Usage: Major primary submissions, mobile CTA, authentication

03. Accessible Touch Targets & Optical Alignment

Separates the visual icon size (16–20px) from its actual interactive surface (≥44–48px on mobile). Min 8px separation.

Touch Area vs. Visual Icon Area

Dashed boundary represents the 48 × 48px interactive touch area. The icon remains 20px.

Complies with WCAG 2.5.5 (44×44px min / 48×48px preferred)
Form Control Hit Surfaces

Checkboxes retain a crisp 18px footprint while expanding click surface to 44px on mobile devices.

No accidental mis-clicks or clipped touch boundaries

04. Soft Shadow & Elevation Levels

Soft, ambient multi-layer shadows establishing clear depth hierarchy without harsh black borders.

Level 0 — Flat No shadow

Standard content, data tables, and static canvas cards.

Level 1 — Subtle 0 2px 8px rgba(0,0,0,0.04)

Surfaces requiring slight background separation.

Level 2 — Interactive 0 6px 18px rgba(0,0,0,0.07)

Elevated interactive cards, hover states, dropdowns.

Level 3 — Floating 0 12px 32px rgba(0,0,0,0.10)

Popovers, floating action bars, selected overlays.

Level 4 — Modal 0 20px 48px rgba(0,0,0,0.14)

Dialog windows, modal sheets, and system alerts.
