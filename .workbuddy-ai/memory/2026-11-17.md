## Master sticky header + responsive scrolling fix
- Root causes: (1) three competing header systems (`layout.js` topbar, hero topbar, page `.mobile-appbar`) with `:has()`-based mutual hiding; (2) duplicated global `background:transparent !important` rules in `design-system.css` and `shared-components.css` targeting `header[role="banner"]` / `header[class*="sticky"]`, so telemetry showed through Security Center chrome; (3) no measurement of real header height — CSS hardcoded 16/48px/5.5rem offsets and conflicting 58/64px variables; (4) duplicate hero topbar stayed visible because `.hero-topbar {display:flex!important}` beat the duplicate-hide rule; (5) mobile dashboards hid the hero and left no compact sticky replacement; (6) fullscreen used `width:100vw` and animated `.main` margins, causing shifts.
- New shared layer: `assets/css/sticky-layout.css` + `assets/js/sticky-layout.js`. One active header is selected by priority (`[data-ngis-sticky-header]` → `.mobile-appbar` → mobile/hero/topbar fallbacks), duplicates are hidden with high-specificity rules, and the controller measures actual rendered height/left/width into `--ngis-sticky-h`, `--ngis-sticky-left`, `--ngis-sticky-width`. `html.ngis-sticky-ready { scroll-padding-top: var(--ngis-sticky-h) }`; second-level sticky rails use `calc(var(--ngis-sticky-h) + 8px)` instead of magic pixels. ResizeObserver + visualViewport + MutationObserver retarget on breakpoint/theme/fullscreen changes. Inline `!important` surface guard defeats duplicate legacy sheets.
- Injected the shared layer from both `assets/js/layout.js` and root `layout.js` so every portal inherits it without per-page script tags. Source transparency rules now exclude `.ngis-sticky-active` (preserving intentional transparency elsewhere). Security Center markup marks its appbar, modal and fullscreen overlays; removed `.main` width/margin transitions and `100vw` in fullscreen. Student/teacher mobile dashboard headers marked `data-ngis-sticky-header`.
- Verified Chromium: 20 representative pages at 1440×900 all fixed at `top:0`, opaque `rgb(255,255,255)`, no backdrop blur, CSS var equals measured height, no horizontal overflow, zero visible duplicate headers. Security Center: 131px desktop / 154px tablet / 113px mobile; tab switching, modal z-order, fullscreen enter/exit (header hidden + `--ngis-sticky-h:0px`, then restored) all pass. Mobile 390/320: dashboards use a 51px compact opaque header; sidebar open/close keeps header at top 0 and scroll position unchanged. Screenshots: docs/security-sticky-final.png, docs/security-sticky-mobile.png, docs/student-sticky-after.png, docs/teacher-sticky-mobile.png.
- Limitation: static preview server returns 404 for `/api/*` endpoints; these pre-existing backend 404s remain in console. iOS Safari / installed PWA were not runnable in the headless browser; safe-area CSS is preserved via `env(safe-area-inset-*)`.
