Key pattern Every page sets window.PAGE = { role, active } before loading assets/js/layout.js. That script renders the correct sidebar and topbar for the role. To change nav items, edit the NAV object in layout.js. To change global styles or tokens, edit the :root block in assets/css/app.css. Brand: --primary #1F6B3A · --accent #F2C230 · --bg #F8FAF5.
