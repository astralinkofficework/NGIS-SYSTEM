## Design Rules & Usage Guidelines
1. **No Decorative Containers**: Icons must appear directly on the card or page surface. Never wrap 3D icons in colored circles, tinted squares, or pill backgrounds.
2. **Dimension Constraints**:
   - Quick Nav cards: `28×28px` to `32×32px` (e.g. `w-7 h-7` to `w-8 h-8`)
   - Card headers: `22×22px` to `26×26px`
   - Empty states: `56×56px` to `64×64px`
   - Modal headers: `24×24px` to `28×28px`
3. **Preserve Functional SVGs**: Simple navigation buttons, table sort chevrons, close dialog triggers, search inputs, and sidebar utility links continue to use official Bootstrap SVG icons. 3D Fluency illustrations are strictly reserved for academic concept representation, quick actions, and empty states.
