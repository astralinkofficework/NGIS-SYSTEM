## 3. ROW DESIGN

Each teacher must appear as a clean horizontal record.

Example layout:

Teacher avatar | Name & ID | Subject | Teacher Code | Target Hours | Status | Actions

Use:

- White surfaces.
- Subtle borders.
- Comfortable spacing.
- Consistent alignment.
- Small, meaningful SVG icons.
- Neutral hover effects.
- Clear typography.
- Minimal visual decoration.

Do not use oversized cards for every teacher.

Do not introduce unnecessary shadows or gradients.

Do not make the row look like a spreadsheet.

Rows should be visually separated with subtle dividers.

### Desktop layout

Show the main teacher details in one horizontal row.

### Tablet layout

Prioritize name, code, subject, workload, and actions.

Move secondary information into the expanded editor.

### Mobile layout

Use a compact stacked row:

Teacher name and avatar at the top.

Subject and teacher code underneath.

Status and actions aligned below.

No horizontal page overflow.
